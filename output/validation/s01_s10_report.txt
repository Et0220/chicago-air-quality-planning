REPRODUCIBLE IMPLEMENTATION FINDINGS

F1 — P2 — Late PurpleAir metadata can corrupt the current history interval.
Location: ingestion/purpleair_poll.py:280-287.
The history branch compares an incoming report with the current interval's
start, rather than the sensor's latest accepted report. Reproduction:
  00:00 report: latitude 41.9;
  02:00 report: latitude 41.9;
  late 01:00 report: latitude 42.0.
pa_sensor correctly retains 41.9 at 02:00, but the open pa_sensor_history row
becomes 42.0 starting at 01:00. Downstream SCD2/location joins can therefore
use the wrong location after 02:00. The existing test only exercises a late
report older than the current interval start and misses this ordering.
Required correction: prevent older reports from replacing current metadata;
if late history is reconstructed, bound it by the next known report. Add this
ordering to regression coverage.

F2 — P2 — PurpleAir ignores the documented environment configuration contract.
Location: ingestion/purpleair_poll.py:460-465 and 484-495.
AIR_QUALITY_PURPLEAIR_MAX_AGE_SECONDS=123 still yields max_age=900;
AIR_QUALITY_PURPLEAIR_STALE_AFTER_SECONDS=456 still yields stale_after=600;
AIR_QUALITY_GCS_RAW_PURPLEAIR_PREFIX=custom/raw/pa still writes raw/purpleair.
These values are read straight from YAML, and .env is loaded afterward.
This silently defeats documented runtime configuration and quality thresholds.
Required correction: resolve CLI > environment > YAML consistently, loading
local environment values before resolution; verify all supported scalars.

F3 — P2 — S10 rejects the custom raw prefix supported by S06.
Location: ingestion/epa_stage.py:197-199.
S06 accepts gcs.raw_epa_prefix / AIR_QUALITY_GCS_RAW_EPA_PREFIX, but S10 hardcodes
raw/epa in its source-path check. A valid recorded URI such as
gs://test/custom/epa/2026/hourly_42101_2026.zip fails immediately with
"Unexpected raw EPA object path". This does not affect today's default paths.
Required correction: use the same configured raw prefix and retain bucket,
filename, generation, size, and checksum validation. Cover the nondefault
prefix across the downloader-to-stager handoff.
